# Changelog

## 1.5.0

- Expand a supported repository to see a practical usage idea and its public source. The live list and workspace action still work without the ideas feed.

## 1.4.1

- Removed **Ask an agent**. A start-up question in some agents (such as Claude Code's Code Mode prompt) swallowed its question, so it often opened an empty agent. **Try in a workspace** stays.

## 1.4.0

- See first sightings and consecutive days observed on all-language lists, without replacing live GitHub ranks or uploading workspace data.

## 1.3.0

- **Ask an agent** about a repository, in the workspace you have open.
- **Try in a workspace**: create a new workspace in one of your projects and start an agent there to evaluate the repository.
- Both show what they will do and start only after you confirm. The agent is chosen in the plugin's settings (Claude Code, Codex or Gemini).
- Expand a row to read the full description and reach its actions.
- A filter box narrows the list.
- `cli.mjs` prints the list as JSON for agents and scripts.
- Icon, cover and screenshot for the plugin directory.
- New access: start agents, create workspaces, the plugin's own settings. Needs Orca 1.4.259 or later.

## 1.2.0

- **Match workspace** language option, a **Saved** tab, a status bar item and two commands.
- New access: read your workspaces.

## 1.1.0

- The panel is drawn with Orca's own components. Period tabs, language select, cached results and a "new" badge.

## 1.0.0

- First release.
